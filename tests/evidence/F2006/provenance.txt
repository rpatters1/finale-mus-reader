    Finale 2006 is the last release to write ETF, which raised the question of
    whether it also began mixing the later class-identified records in with the
    fixed 16-byte rows. It does not: its others, details, and third blocks are
    all whole multiples of the row size and a class-record walk consumes none of
    them. The only structural difference from Finale 2005 is a fifth, empty
    0x0013 block, which this file carries.
