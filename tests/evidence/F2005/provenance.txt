F2005-clef-baseline: from F2005-baseline, Clef Designer baseline adjustment set on two clefs.
  Clef 0 (treble): 1 inch requested. The document's measurement unit was inches, so this is
  288 Evpu and the file stores 18432 Efix.
  Clef 1 (bass): -2 inches requested. That is -36864 Efix, which does not fit the signed
  16-bit stored field, so Finale saturated it to -32768 and the dialog reads it back as
  -1.7778 inches.

F2005-courtesy-clef-off: from F2005-baseline, "Display Courtesy Clef at End of Staff
  System" turned off and the key and time signature courtesies left on. Selector 44
  word 3 moves 7 -> 3, so the clef's courtesy is bit 2.

F2005-courtesy-key-off: from F2005-baseline, only the courtesy key signature turned
  off. Selector 44 word 3 moves 7 -> 6, so the key signature's courtesy is bit 0.
  This is the save that distinguishes the clef bit from a bit that merely happened to
  be clear; time is bit 1 by elimination.

F2005-insert-sharp-font.mus
    sha256 5646429f2f86fac67023b645874b32b81facf53294f2702d750dccda3d99439b
    From F2005-baseline, the sharp accidental insert's symbol font set to Petrucci at 79%
    with bold. Bytes 10, 12 and 14 of the block's first element move to 9, 79 and 1. The
    source's own ^FN(9) is "Petrucci", and the companion resolves the same face, which is
    what shows the field is a font-definition comparator in the source's numbering.

F2005-textvert-center.mus
    sha256 4fee0d73fa505cba481431c695d4df9d01f1a69bd319209b6e764a2a17e404d3
    From F2005-baseline, the vertical alignment set to Center and nothing else. Selector 83

F2005-linespace-to-evpu.mus
    sha256 4e03b6187689ad6daa21c81709d3e6751eff8d8acdce179f9bede390150e4494
    From F2005-baseline, the line spacing switched from 100 percent to an absolute 72 Evpu.
    Selector 82 words 0 and 1 move, 100 -> 72 and 1 -> 0, and the companion replaces
    <textLineSpacingPercent>100</> with <textLineSpacingEvpu>72</> while keeping
    <textExpandSingleWord/>. Word 1 selects which of the two musxdom members word 0
    populates. Finale 27 has no boolean for that mode -- it writes one element or the other --
    so only a save that moves the units alone can fix the word.
